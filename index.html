        Organización del sistema según el modelo multicapa cliente-servidor web, Arquitectura Hexagonal (Ports & Adapters) y servicios en la nube.

Capa Cliente (Frontend SPA)

              
Navegador Web en Equipos del Colegio

            

          

          

            Interfaz Web Isométrica 2D
            HTML5, CSS3 moderno y JavaScript (React App SPA). Sin instalaciones locales pesadas.
          

          

            Motor Gráfico Canvas Molecular
            Renderizado dinámico de partículas atómicas a 60 FPS con detección de colisiones físicas.
          

          

            Dispositivos Compatibles
            Equipos del aula de cómputo del Colegio Alexander Fleming con 4 GB de RAM y GPU estándar.
          

        


        
        

          

            
⚙️

            

              
Capa Servidor (Backend Cloud)

              
Servidor de Aplicaciones Java Spring Boot

            

          

          

            Arquitectura Hexagonal (Ports & Adapters)
            Desacoplamiento total entre la lógica del dominio químico y los controladores web externos.
          

          

            Núcleo ReactionEngine
            Motor de dominio que calcula la diferencia de electronegatividad (ΔEN de Pauling) y clasifica enlaces.
          

          

            Servicio de Caché en Memoria
            Almacena respuestas de PubChem API resolviendo consultas frecuentes en menos de 50 ms.
          

          

            Generador Asíncrono de Reportes
            Compilación automática de informes en formato PDF sin bloquear los procesos del servidor.
          

        


        
        

          

            
🗄️

            

              
Persistencia & Servicios Cloud

              
Base de Datos PostgreSQL y Servicios Externos

            

          

          

            PostgreSQL Relacional
            Gestión estructurada de usuarios (Estudiante, Docente, Admin), grupos, historial de intentos y notas.
          

          

            PubChem PUG-REST API (NCBI)
            Fuente oficial para consulta de pesos moleculares, radios atómicos y configuraciones electrónicas.
          

          

            Seguridad & Comunicaciones HTTPS
            Cifrado TLS, certificados digitales SSL y cumplimiento de la Ley de Protección de Datos (Ley 29733).
          

          

            Hosting en la Nube (VPS)
            Instancia en Render / Railway configurada para 30 estudiantes concurrentes (1 vCPU, 2 GB RAM).
          

        

      


      
      

        

          📐 Flujo de Comunicación entre Capas
        

        

          

            1. Solicitud de Práctica
            
El estudiante inicia sesión y selecciona una práctica curada desde el navegador del aula.

          

          

            2. Procesamiento Científico
            
El ReactionEngine evalúa las colisiones e interactúa con el adaptador de PubChem para cargar radios y cargas.

          

          

            3. Evaluación y Almacenamiento
            
Al terminar el quiz, el servidor registra la nota en PostgreSQL y genera el reporte PDF para el docente.
